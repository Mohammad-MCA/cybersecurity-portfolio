# 08 – Automate Cybersecurity Tasks with Python

**Course:** Automate Cybersecurity Tasks with Python  
**Portfolio Activity:** Write Python scripts to automate security-related file and log tasks

---

## Overview

Python is widely used by security analysts for parsing logs, updating configurations, and automating repetitive tasks. This folder contains practical example scripts aligned with the course.

## Scripts Included

| Script | Purpose |
|--------|---------|
| [`update_file_permissions.py`](./update_file_permissions.py) | Demonstrates algorithmic updating of file permissions / ownership concepts |
| [`log_parser.py`](./log_parser.py) | Simple log parsing example for failed login detection |

## Skills Demonstrated

- Reading and writing files with Python  
- String parsing and regular expressions  
- Conditional logic for security decisions  
- Writing clean, documented, reusable scripts  

## How to Run

```bash
# Example
python3 update_file_permissions.py
python3 log_parser.py sample_auth.log
```

*Replace or extend these scripts with the exact algorithms and solutions you developed in the course labs.*
