# 04 – Managing File Permissions in Linux

**Course:** Tools of the Trade: Linux and SQL  
**Portfolio Activity:** Manage file and directory permissions using Linux commands

---

## Overview

Proper file permissions are a core part of the principle of least privilege. This project documents common Linux permission commands and best practices used in security operations.

## Deliverable

See [`linux-permissions-guide.md`](./linux-permissions-guide.md) for a practical reference of commands and scenarios.

## Skills Demonstrated

- Linux command-line proficiency  
- Understanding of owner / group / others and rwx bits  
- Applying least privilege  
- Using `chmod`, `chown`, `ls -l`, `umask`, and related tools
