# Prioritized Recommendations – Botium Toys

## High Priority (Immediate – 0–30 days)

1. **Implement encryption for sensitive data at rest**  
   Encrypt databases and file shares that store customer or payment-related information. This directly addresses PCI DSS and GDPR confidentiality requirements.

2. **Enforce multi-factor authentication (MFA)**  
   Require MFA for all administrative and remote access accounts.

3. **Establish regular, tested backups**  
   Implement automated backups with off-site or cloud copies and perform recovery tests. Critical for ransomware resilience and business continuity.

4. **Document and enforce least-privilege access**  
   Review all user accounts, remove excessive permissions, and apply role-based access control (RBAC).

## Medium Priority (30–90 days)

5. **Deploy an Intrusion Detection System (IDS)**  
   Install and tune an IDS (e.g., Suricata) to improve detection capability.

6. **Create a formal Incident Response Plan**  
   Develop playbooks aligned with NIST CSF and define roles, communication channels, and escalation paths.

7. **Launch security awareness training**  
   Conduct regular training covering phishing, password hygiene, and data handling.

8. **Formalize patch management**  
   Establish a monthly patching cadence and vulnerability scanning process.

## Lower Priority / Continuous Improvement

9. **Expand logging and monitoring**  
   Centralize logs and consider a lightweight SIEM solution as the business grows.

10. **Review and update security policies annually**  
    Ensure policies stay aligned with business changes and regulatory requirements.

11. **Vendor risk management**  
    Add basic security questionnaires for key third-party providers.

---

### Expected Outcomes

- Reduced risk of data breach and ransomware impact  
- Improved compliance posture for PCI DSS / GDPR  
- Faster detection and response capability  
- Clear evidence of due diligence for leadership and auditors
