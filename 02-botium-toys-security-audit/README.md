# 02 – Botium Toys Internal Security Audit

**Course:** Play It Safe: Manage Security Risks  
**Portfolio Activity:** Conduct a security audit for Botium Toys

---

## Scenario Summary

Botium Toys is a fictional small U.S. business that sells toys online and in physical stores. As an IT security associate, you perform an internal security audit to evaluate current controls, assess compliance gaps (PCI DSS, GDPR, SOC), and provide prioritized recommendations.

## Key Deliverables in This Folder

| File | Description |
|------|-------------|
| [`controls-assessment.md`](./controls-assessment.md) | Evaluation of existing technical, administrative, and physical controls |
| [`compliance-checklist.md`](./compliance-checklist.md) | Checklist against PCI DSS, GDPR, and SOC requirements |
| [`recommendations.md`](./recommendations.md) | Prioritized, risk-based recommendations for leadership |

## Skills Demonstrated

- Risk identification and prioritization  
- Security controls assessment (least privilege, encryption, backups, IDS, etc.)  
- Compliance awareness (PCI DSS, GDPR, SOC)  
- Clear stakeholder communication and documentation
