# Controls Assessment – Botium Toys

## Administrative / Managerial Controls

| Control | Present? | Notes |
|---------|----------|-------|
| Written security policies | Partial | Basic policies exist but lack regular review |
| Risk assessment process | Yes | Formal risk assessment performed for this audit |
| Security awareness training | No | No formal training program for employees |
| Incident response plan | No | No documented IR plan or playbooks |
| Separation of duties | No | Single IT staff member handles multiple critical functions |
| Vendor / third-party risk management | Partial | Limited formal review of vendors |

## Technical Controls

| Control | Present? | Notes |
|---------|----------|-------|
| Firewall | Yes | Basic firewall in place |
| Antivirus / anti-malware | Yes | Endpoint protection installed |
| Encryption (data at rest) | No | Local data stores are not encrypted |
| Encryption (data in transit) | Partial | HTTPS used on website; internal traffic unencrypted |
| Intrusion Detection System (IDS) | No | No IDS/IPS deployed |
| Multi-factor authentication (MFA) | No | Not enforced for critical systems |
| Password policy / management | Partial | Basic complexity rules; no password manager or rotation policy |
| Regular backups | No | No documented backup or recovery process |
| Patch management | Partial | Ad-hoc updates; no formal schedule |
| Access control / least privilege | No | Excessive permissions common |

## Physical Controls

| Control | Present? | Notes |
|---------|----------|-------|
| Physical locks on doors | Yes | Store and office secured |
| CCTV / video surveillance | Yes | Cameras present |
| Fire detection / suppression | Yes | Basic systems installed |
| Visitor access logs | Partial | Informal process |

## Summary of Critical Gaps

1. Missing encryption for sensitive data at rest  
2. No IDS / continuous monitoring capability  
3. No formal backups or disaster recovery plan  
4. Lack of least-privilege access controls and MFA  
5. No incident response plan or security awareness training  

These gaps increase the likelihood and impact of data breaches, ransomware, and compliance violations.
