# Security Policy

## Reporting a Vulnerability

If you discover a security issue in any of the example scripts or documentation in this portfolio, please open a private security advisory on GitHub or contact the repository owner directly.

## Important Notes

- This repository is an **educational portfolio**.
- Sample log data and IP addresses are fictional (RFC 5737 documentation ranges).
- Never commit real credentials, private keys, production logs, or personally identifiable information.
- The Python scripts are demonstration-only and are not intended for production security monitoring without significant hardening and testing.
