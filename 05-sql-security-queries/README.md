# 05 – Applying Filters to SQL Queries

**Course:** Tools of the Trade: Linux and SQL  
**Portfolio Activity:** Write and filter SQL queries for security log analysis

---

## Overview

SQL is essential for querying security logs, user activity, and incident data stored in databases. This project demonstrates filtering, joining, and extracting security-relevant information.

## Deliverable

See [`sql-queries.md`](./sql-queries.md) for sample queries commonly used in security investigations.

## Skills Demonstrated

- Writing SELECT statements with WHERE, AND, OR, LIKE, IN  
- Filtering by date, user, IP, status codes  
- Basic aggregation for anomaly detection  
- Understanding of data protection when querying sensitive tables
