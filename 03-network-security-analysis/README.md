# 03 – Network Security Analysis

**Course:** Connect and Protect: Networks and Network Security  
**Portfolio Activity:** Analyze network structure, attacks, and hardening measures

---

## Overview

This project demonstrates understanding of network architecture, common attack patterns (e.g., SYN flood, DNS/ICMP anomalies), and practical hardening techniques.

## Deliverable

See [`network-analysis-report.md`](./network-analysis-report.md) for a sample analysis report covering:

- Network layer communication concepts  
- Identification of suspicious traffic patterns  
- Hardening recommendations (firewall rules, OS hardening, segmentation)

## Skills Demonstrated

- Reading and interpreting packet captures (Wireshark / tcpdump concepts)  
- Recognizing common network attacks  
- Applying defense-in-depth and network hardening principles  
- Clear technical documentation
